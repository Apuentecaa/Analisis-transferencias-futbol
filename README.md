# Análisis de Transferencias de Fútbol 2010-2026

## Descripción del Proyecto
Proyecto de análisis de datos del mercado de transferencias de fútbol utilizando **SQL Server**. El objetivo es explorar la relación entre el poder financiero de los clubes y su rendimiento deportivo.

## Aplicación en el Sector Financiero
Este proyecto demuestra habilidades críticas para el sector financiero:
- Análisis de inversión y retorno (ROI)
- Evaluación de riesgos financieros
- Análisis de deuda y rentabilidad
- Modelado de datos relacionales
